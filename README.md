# دليل الذكي: إيجنت التسويق بالعمولة

إيجنت بيشتغل لحاله كل يوم على GitHub: بيختار أداة رقمية، بيبحث عنها، بيكتب مقال وسكربت فيديو بنظام الهوكات، بيعمل فيديو قصير بصوت عربي، وبيبعتلك ياه على تيليغرام. إنت بتضغط "وافق"، والمقال بينزل على موقعك، وإنت بتنشر الفيديو على تيك توك وسناب وإنستغرام.

## كيف بيشتغل يومك

| الوقت (السعودية) | مين | شو بيصير |
| --- | --- | --- |
| 9:00 الصبح | الإيجنت | بيختار منتج من `products.yaml` وبيبحث عنه (Tavily) |
| 9:05 | الإيجنت | Claude بيكتب الهوكات، السكربت، المقال، والكابشن |
| 9:10 | الإيجنت | صوت عربي (Edge TTS) وفيديو (Remotion) وصورة غلاف |
| 9:15 | إنت | بتوصلك رسالة على تيليغرام فيها الفيديو وأزرار: وافق، عدّل، ارفض |
| بعد ما توافق | الإيجنت | المقال بينزل على الموقع، وبيبعتلك الكابشن جاهز تنسخه |
| بالليل 8 إلى 11 | إنت | بتنشر الفيديو على تيك توك وسناب وإنستغرام (5 دقايق) |
| كل جمعة | الإيجنت | تقرير أسبوعي واقتراح منتجات جديدة |

إذا ضغطت "عدّل": ردّ على رسالة البوت بملاحظتك، وبتوصلك نسخة جديدة خلال 10 دقايق.
أوامر البوت: `/new` مسودة جديدة هسا، `/status` شو الوضع.

## الإعداد (مرة وحدة، تقريباً 30 دقيقة)

### 1. المفاتيح
| المفتاح | من وين | الكلفة |
| --- | --- | --- |
| `ANTHROPIC_API_KEY` | console.anthropic.com ← API Keys | تقريباً 3 إلى 6 دولار بالشهر لمسودة يومية |
| `TAVILY_API_KEY` | app.tavily.com | مجاني (1000 بحث بالشهر) |
| `TELEGRAM_BOT_TOKEN` | بتيليغرام احكي مع @BotFather واكتب `/newbot` | مجاني |
| `TELEGRAM_CHAT_ID` | ابعت أي رسالة لبوتك، بعدين افتح `https://api.telegram.org/bot<TOKEN>/getUpdates` وخذ رقم `chat.id` | مجاني |
| `PINTEREST_TOKEN` (اختياري) | developers.pinterest.com | مجاني |

### 2. حط المفاتيح بـ GitHub
المستودع ← Settings ← Secrets and variables ← Actions ← New repository secret. كل مفتاح باسمه بالضبط.
**لا تحط أي مفتاح جوا الكود أو بملف.**

### 3. شغّل الموقع
Settings ← Pages ← Source: اختار **GitHub Actions**.
الموقع رح يكون على: `https://yazanmaharmehai-oss.github.io/daleel-agent/`
رابط البايو بكل المنصات: `https://yazanmaharmehai-oss.github.io/daleel-agent/links/`

### 4. روابط العمولة
سجّل ببرامج العمولة (Arabclicks، Admitad، أو برنامج الشركة نفسها). لما يعطوك رابط، حطه بـ `products.yaml` عند المنتج بـ `affiliate_url` وغيّر `status` لـ `ready`. المقالات القديمة بتتحدث لحالها لأن الأزرار بتمر من صفحة `/go/`.

### 5. جرّب
Actions ← daily-draft ← Run workflow. خلال 10 دقايق لازم توصلك أول مسودة على تيليغرام.

## مكونات المشروع
```
agent/          الإيجنت (Python)
  research.py   بحث Tavily: الحقائق من الموقع الرسمي والمراجعات
  writer.py     Claude: هوكات، مشاهد الفيديو، المقال، الكابشن (مخرجات منظمة)
  voice.py      صوت عربي مجاني (Edge TTS) مع توقيت كل كلمة للترجمة
  video.py      رندر الفيديو والغلاف بـ Remotion
  site.py       الموقع العربي الثابت
  telegram.py   بوت الموافقة
  main.py       التشغيل: daily, approvals, build, weekly
video/src/      قالب الفيديو (Remotion): hook, problem, before_after, feature, offer, cta
site/           الخطوط، التصميم، والمقالات المنشورة (content/)
products.yaml   قائمة المنتجات وروابط العمولة
config.yaml     الاسم، الصوت، الموديل، الأسواق
.claude/skills/ مهارات Claude: الهوكات العربية، حزمة النشر، Tavily، Remotion
```

## تشغيل محلي (للمطورين)
```bash
pip install -r requirements.txt
(cd video && npm ci)
python -m agent daily --dry-run --product canva   # بدون مفاتيح: محتوى تجريبي + فيديو
python -m agent build                              # الموقع بـ site/_build
```

## قواعد ما بنكسرها
- كل فيديو ومقال فيه #إعلان وإفصاح إنه رابط عمولة.
- الأسعار والميزات فقط من مصادر البحث. إذا معلومة ناقصة بتطلع [تأكد] وبيحذرك البوت.
- ما في نشر باسمك بدون موافقتك.
- Remotion مجاني للأفراد والشركات لحد 3 موظفين. إذا كبر الفريق لازم رخصة.
